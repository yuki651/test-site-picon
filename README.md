## 無料で公開する方法（GitHub Pagesの例）
1. GitHubでアカウントを作成／ログインします。
2. 新しい公開リポジトリを作成します（例：`mixbar-picon`）。
3. `index.html`、`styles.css`、`script.js` をリポジトリ直下にアップロードします。
4. リポジトリの **Settings → Pages** を開き、公開元を `Deploy from a branch`、ブランチを `main`、フォルダを `/(root)` に設定して保存します。
5. 公開URLが表示されるまで待ちます。通常は `https://ユーザー名.github.io/mixbar-picon/` の形式です。

GitHubの画面表示は更新される場合があります。公開リポジトリにすると、アップロードしたソースコードは誰でも見られます。公開したくない情報や個人情報を入れないでください。

## CSSを手作業で調整するには

デザインの調整は `styles.css` をメモ帳で開いて行います。今回、ルールを読みやすい改行・インデントに整理しました。

- **色の変更**：ファイル上部の `:root` にある `--pink`、`--yellow`、`--blue`、`--purple` などを変更します。
- **文字や余白・配置**：各セクションの見出し（例：`04. Official PICON logo`）を目印に探します。
- **スマートフォン表示**：`@media (max-width: 560px)` や `@media (max-width: 700px)` の中が主な調整場所です。
- **ワイングラスの見た目**：末尾付近の `09. Hero illustration: wine glasses` セクションが対象です。
- **注意**：CSSは後ろに書かれた指定が優先される場合があります。今回は見た目を保つため、ルールの順序は変更していません。

編集前に `styles.css` をコピーしてバックアップを作り、少しずつ変更してブラウザーを再読み込みすると安心です。


## Googleカレンダーの埋め込み

「店内・スタッフ」の下に「営業カレンダー」を追加し、Googleカレンダーを表示するようにしています。

- 表示場所や見出し：`index.html` の `id="calendar"` の部分
- カレンダーのURL：同じ部分の `<iframe>` 内の `src`
- 表示の高さや枠：`styles.css` の「10. 営業カレンダー」
- カレンダーが表示されない場合：Googleカレンダーの設定で、対象カレンダーの公開・共有設定をご確認ください。一般公開にすると予定の詳細も閲覧できる場合があるため、公開してよい予定だけを載せたカレンダーを使用してください。

## お問い合わせフォーム（要初期設定）
- お問い合わせ欄を追加し、送信先を `info@picon.tokyo` に設定しています。
- 送信には外部フォーム送信サービス「FormSubmit」を利用します。フォームに入力された氏名・メールアドレス・お問い合わせ内容は、送信処理のため同サービスを経由します。
- **公開前に、サイトをサーバーへアップロードしたうえで、フォームからテスト送信してください。** FormSubmitでは初回に受信先メールアドレスの確認・有効化が求められる場合があります。受信先に届く案内メールを確認し、有効化が完了してから実際の受付を開始してください。
- テスト送信が届くこと、返信先が正しいこと、迷惑メールフォルダーに振り分けられていないことを確認してください。
- 外部サービスの仕様・利用条件・プライバシーポリシーを確認してから公開してください。フォーム送信が成功しても、ブラウザーに送信完了ページが表示される仕様になる場合があります。
- 現在のZIPを開くだけでは実際のメール送信テストはできません。公開サーバーへ設置してから確認してください。
