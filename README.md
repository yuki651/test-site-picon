# MixBarピコン Webサイト試作品

## ファイル
- `index.html`：ページ本文
- `styles.css`：色・レイアウト・スマートフォン対応
- `script.js`：スマートフォン用ナビゲーション、フッター年号

## ローカルで確認
3ファイルを同じフォルダに置き、`index.html` をブラウザで開いてください。

## 無料で公開する方法（GitHub Pagesの例）
1. GitHubでアカウントを作成／ログインします。
2. 新しい公開リポジトリを作成します（例：`mixbar-picon`）。
3. `index.html`、`styles.css`、`script.js` をリポジトリ直下にアップロードします。
4. リポジトリの **Settings → Pages** を開き、公開元を `Deploy from a branch`、ブランチを `main`、フォルダを `/(root)` に設定して保存します。
5. 公開URLが表示されるまで待ちます。通常は `https://ユーザー名.github.io/mixbar-picon/` の形式です。

GitHubの画面表示は更新される場合があります。公開リポジトリにすると、アップロードしたソースコードは誰でも見られます。公開したくない情報や個人情報を入れないでください。

## 公開前に必ず変更する項目
- 料金：「要確認」の箇所を実際の料金・税・サービス料に置き換える
- 営業時間・定休日
- 正式な住所、最寄り駅、徒歩時間
- Instagramリンク（現在はInstagramトップへの仮リンク）
- 店内・スタッフ写真（現在はCSSの仮デザイン）
- お店の連絡先など必要な情報

## 注意
この試作品にはバックエンドや予約フォームはありません。外部サービスのアカウント、ドメイン、予約・決済機能などが必要な場合は別途設定が必要です。Google Fontsを読み込むため、ネット接続があると指定フォントが使われます。
